# adres

[![CI](https://github.com/ardazeybek-dev/adres/actions/workflows/ci.yml/badge.svg)](https://github.com/ardazeybek-dev/adres/actions/workflows/ci.yml)
[![PyPI](https://img.shields.io/pypi/v/adres-tr.svg)](https://pypi.org/project/adres-tr/)

Split free-form Turkish addresses into their parts: province, district,
neighbourhood, avenue, street, building number, floor, flat and postal code.

Addresses typed into checkout forms, CRMs and spreadsheets come in every shape:
`KADIKÖY/İST.`, `kadikoy istanbul`, `No:12/3`, `D:3`, `Kat 2`, `1453 Sk.`,
`Mah.Moda Cad.` with no space. `adres` reads them all and checks the province
and district against the official list of **81 provinces and 973 districts**.
No dependencies, no network calls.

```bash
pip install adres-tr
```

```python
>>> from adres import parse
>>> a = parse("Caferağa Mah. Moda Cad. No:12/3 34710 Kadıköy/İSTANBUL")
>>> a.neighbourhood, a.avenue, a.building_no, a.apartment
('Caferağa', 'Moda', '12', '3')
>>> a.district, a.province, a.plate
('Kadıköy', 'İstanbul', 34)
>>> parse("bostanci mh. bagdat cd no 21 kadikoy istanbul").format()
'Bostanci Mah. Bagdat Cad. No:21 Kadıköy/İstanbul'
```

## What it handles

| Input | Result |
| --- | --- |
| `Kadıköy/İstanbul`, `Bornova - İzmir`, `ÇANKAYA ANKARA` | district + province, official spelling |
| `kagithane istanbul`, `IĞDIR`, `Hakkari` | `Kâğıthane`, `Iğdır`, `Hakkâri` (Turkish I/İ handled) |
| `Mah.` `Mh.` `Mahallesi` · `Cad.` `Cd.` · `Sk.` `Sok.` · `Blv.` · `Sitesi` · `Apt.` · `Köyü` | neighbourhood, avenue, street, boulevard, site, building, village |
| `No:12/3`, `No 12`, `Atatürk Cad. 36/1` | building number 12/36, flat 3/1 |
| `Kat:2`, `2. Kat`, `Zemin Kat`, `D:3`, `Daire 4`, `İç Kapı No:5` | floor, flat |
| `B Blok`, `Blok A`, `5. Blok` | block |
| `12. Sokak`, `1453 Sk.`, `372/8 Sokak` | numbered streets (not taken for door numbers) |
| `Merkez/Kütahya`, `Hakkari merkez` | the central district |
| `Afyon`, `Antep`, `Urfa`, `K.Maraş`, `İçel`, `İST.`, `Eyüp`, `Kazan` | current official names |
| `Haliliye`, `Bodrum`, `Atakum` alone | province filled in from the district |
| `16000` alone | province from the postal code (first two digits = plate number) |

When it is not sure, it says so instead of guessing:

```python
>>> a = parse("Selimiye Mah. Ereğli")      # Ereğli is in Konya and in Zonguldak
>>> a.district, a.province
(None, None)
>>> a.warnings
["district 'Ereğli' exists in Konya, Zonguldak; province needed"]
>>> parse("Moda Cad. No:5 Kahve Dünyası yanı Kadıköy").rest
'Kahve Dünyası yanı'
```

Text it does not recognise goes to `rest`, so nothing is silently dropped. A
postal code that belongs to another province than the one written adds a warning.

## Fields

`parse()` returns an `Address`. Every field is a string or `None`.

| Field | Turkish | Example |
| --- | --- | --- |
| `province` | il | `İstanbul` |
| `district` | ilçe | `Kadıköy` |
| `neighbourhood` | mahalle | `Caferağa` |
| `village` | köy | `Karaağaç` |
| `boulevard` | bulvar | `Atatürk` |
| `avenue` | cadde | `Moda` |
| `street` | sokak | `1453` |
| `site` | site | `Ihlamur` |
| `building` | apartman | `Gül` |
| `block` | blok | `B` |
| `building_no` | kapı no | `12` |
| `floor` | kat | `2` (`0` ground, `-1` basement) |
| `apartment` | daire / iç kapı | `3` |
| `postal_code` | posta kodu | `34710` |
| `plate` | plaka (int) | `34` |
| `rest` | | unrecognised text |
| `warnings` | | list of doubts |

`a.to_dict()` gives a plain dict, `a.format()` the cleaned one-line address.

## Lookups

```python
>>> from adres import districts, plate_of, provinces, lookup_postal_code
>>> len(provinces()), len(districts("istanbul"))
(81, 39)
>>> plate_of("K.Maraş"), plate_of("IĞDIR")
(46, 76)
>>> lookup_postal_code("34710")
('İstanbul', 'Kadıköy')
>>> lookup_postal_code("06830")      # two district ranges overlap: no guess
('Ankara', None)
```

## Command line

```bash
adres "Caferağa Mah. Moda Cad. No:12/3 Kadıköy/İstanbul"   # JSON
adres --line < addresses.txt                                # one cleaned address per line
adres --csv < addresses.txt > addresses.csv                 # one column per part
```

Without `--line` or `--csv`, several input lines are printed as JSON Lines.

## Limits

- Neighbourhood, street and site names are taken from the text as written
  (title-cased), not checked against a list: `bostanci` stays `Bostanci`.
- A district written without its province is resolved only when the name is
  unique in Turkey (23 names such as Ereğli, Gölbaşı and Yenişehir are not).
- Postal ranges come from the district list and overlap in places, so a postal
  code alone gives the district only when exactly one range holds it.

## Data

`src/adres/_data.py` is generated by `scripts/build_data.py` from the table in
the Turkish Wikipedia article
[Türkiye'nin ilçeleri](https://tr.wikipedia.org/w/index.php?oldid=37373921),
pinned to one revision (CC BY-SA 4.0). The script checks for 81 provinces and
973 districts and that every postal range starts with its province's plate
number. Five ranges in the source failed that check: two obvious typos are
corrected, three are left empty (see `POSTAL_FIXES` in the script).

```bash
python scripts/build_data.py     # regenerate from the pinned revision
```

## Pitfalls

- `"İSTANBUL".lower()` in Python is `"i̇stanbul"` (with a combining dot), and
  `"ISPARTA".lower()` is `"isparta"` instead of `"ısparta"` → compare with
  `adres.fold()`, never with `str.lower()`.
- Wikipedia lists Zonguldak's district as "Karadeniz Ereğli" to tell it apart
  from Konya's; the official name is Ereğli → keep the rename in `DISTRICT_NAMES`
  when regenerating the data.
